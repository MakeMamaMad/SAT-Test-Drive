# SAT Test Drive

Сайт записи на тест-драйв SAT-500 и SAT-545.

## Возможности

- Адаптивная главная страница, выбор модели, анкета.
- PHP/MySQL API для сохранения заявок.
- Две независимые очереди: SAT-500 и SAT-545.
- Персональная ссылка с 256-битным случайным токеном для проверки позиции.
- Статус и позиция рассчитываются из базы, а не из браузера.

**GitHub Pages показывает только дизайн. PHP на GitHub Pages не работает.**
Не включайте реальный сбор заявок до настройки сервера, публикации полноценной политики персональных данных и административного рабочего процесса.

## Установка на REG.RU ISPmanager

1. Создайте отдельный тестовый сайт/поддомен на хостинге с PHP 8.1+ и PDO MySQL.
2. Создайте MySQL базу и пользователя с доступом только к ней.
3. Импортируйте `database/schema.sql` через phpMyAdmin.
4. Скопируйте `config.example.php` как `sat-test-drive-config.php` **на один уровень выше публичного каталога сайта**, а не внутрь него; заполните реквизиты базы.
5. Загрузите содержимое репозитория в публичный каталог тестового сайта.
6. Настройте HTTPS, приватность, администрирование и защиту от злоупотреблений перед реальным запуском.

## Безопасность и ограничения

- Ссылка-токен даёт доступ к номеру заявки, модели и месту в очереди. Не публикуйте её.
- Данные пользователей не должны размещаться в GitHub.
- Перед production: rate limiting, защита от ботов, уведомления, ограничение дублей, ретеншн/удаление ПД, утверждённая политика и проверка прав доступа.
- Пока нет закрытой панели администратора, смена статусов возможна только через ограниченный доступ к MySQL.
- Позиция относится только к заявкам со статусом `waiting` той же модели.
