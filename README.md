# SAT Test Drive

Стартовый дизайн сайта тест-драйвов **SAT-500** и **SAT-545**.

## Что реализовано
- адаптивная главная страница в фирменном лаймовом стиле;
- карточки двух моделей с предварительными характеристиками;
- анкета: модель, ФИО, телефон, email, согласие;
- демонстрационный режим (отправка персональных данных **отключена**);
- заглушка страницы о персональных данных.

## Следующие этапы
1. Проверка заводских характеристик, добавление официальных фотографий.
2. API PHP + MySQL с безопасной регистрацией и независимыми очередями SAT-500 / SAT-545.
3. Персональная ссылка для просмотра позиции и закрытая админ-панель.
4. Защита от злоупотреблений и дублей, ограничение частоты запросов, политика конфиденциальности.
5. Развёртывание на тестовом поддомене REG.RU.

## Запуск
Откройте `index.html` локально или загрузите статические файлы на тестовый поддомен. Для демонстрации не нужны PHP или база данных.

**Не использовать для реального сбора заявок до настройки серверной части.**

Официальный каталог для проверки характеристик: https://www.satpricep.by/
